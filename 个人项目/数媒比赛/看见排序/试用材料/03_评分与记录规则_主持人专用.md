# 前后测评分与任务记录规则：主持人专用

规则版本：V1，2026 年 10 月 15 日。与 `02_前后测题本.md` V1 配套。**不要在前测或后测前向参与者展示本文件。**每题 0—2 分，每份题本最多 6 分；评分规则在首位结构化参与者开始前固定。改题/改规则须另设版本并分开报告。

## 1. A 题：行为与目的

前测和后测的参考逻辑相同：不能。模型只记录相同点击和卡片 ID，初始状态相同，没有记录能够区分两种动机的信息。可以补充用户主动表达等额外线索，但不能把补充信息说成本题已经采集。

| 分数 | 评分锚点 |
| --- | --- |
| 2 | 明确不能区分，并说明相同事件/初态或缺少目的信息；意思准确即可 |
| 1 | 仅答不能，缺少理由；或已指出信息不足但否定表述不清 |
| 0 | 认为仅凭本题相同点击就能知道真实目的；或给出不相关/相反解释 |

作答“现实系统也许有其他数据，但本题不能”应得 2 分。“算法永远不可能了解任何偏好”不属于准确理由，按其是否仍正确指出本题信息限制评分并加注误解。

## 2. B 题：有效对照

前测和后测的参考逻辑相同：不能。右侧同时改变了参数和动作历史，不能只归因于权重。恢复/复制同一快照，去掉额外点击，保持内容池、初始状态、动作历史和规则一致，仅改 `λ` 后重算。

| 分数 | 评分锚点 |
| --- | --- |
| 2 | 明确比较不能单独归因，并给出恢复相同状态/历史、只改权重的可行重做方法 |
| 1 | 判断有问题但未给重做方法；或提出控制变量但没有说清需要同一状态/历史 |
| 0 | 直接把变化全归于权重，认为额外点击无关，或提出继续改变其他条件 |

“两边都使用完全相同的新增点击历史再只改权重”也是可行方法；若说得清楚应得 2 分。无需要求参与者逐字背出全部固定条件，关键是消除额外点击的混杂。

## 3. C 题：排序解释

前测：A=`.6×.2+.4×(.2+.4)/2=.24`；B=`.6×.2+.4×(.8+.6)/2=.40`，B 在前。

后测：C=`.6×.25+.4×(.3+.5)/2=.31`；D=`.6×.25+.4×(.7+.9)/2=.47`，D 在前。

| 分数 | 评分锚点 |
| --- | --- |
| 2 | 次序正确，并给出正确算分，或准确指出兴趣分相同而另一卡 p/f 平均值更高且权重为正 |
| 1 | 次序正确但没有有效理由；或思路正确，局部计算错误导致最终次序写错，需注明 |
| 0 | 没有合理依据且次序错误，或把任意一项当唯一条件作出相反判断 |

可用计算器；前后测条件保持一致。允许等价分数和小数写法。排名相同但“因为它更受所有人喜欢”不是有效依据，最多 1 分并标记误解。

## 4. 缺失、帮助与评分复核

- 空白、拒答、退出、技术故障记为“缺失＋原因”，不要自动记 0。参与者明确写“不知道”且完成该题作答时记 0，并保留原文。
- 题目原始答案不改写。先抄录原文，再单列分数与理由；语句含糊时不得用主持人的理解替换参与者的话。
- 主持人若提示了答案或提前展示参考答案，标出受影响题目；原始记录保留，结果单列，不当作独立测验表现。
- 有两名评分者时，可独立评分后比较；没有则如实写单人评分。出现分歧保留两份原分及协商理由，不倒改记录。
- 只有三题均有有效作答时才给该份“完整总分”。缺失个案不补分，按题使用实际有效分母。

## 5. 应用内任务的过程评价

应用的报告题与前后测分开记录，不把同一任务重复算成两份独立学习证据。

| 子任务 | 观察到什么才记完成 | 记录方式 |
| --- | --- | --- |
| T1 行为与动机 | 能指出记录相同但动机未记录 | 独立完成/提示后完成/未完成/未到达，及原话 |
| T2 解释卡片 | 找到面板，正确指出至少一项输入和权重关系 | 同上，另记是否把分数当概率 |
| T3 单条件比较 | 从同一快照保持历史一致，仅改变 λ 并运行 | 同上，另记实际条件 |
| T4a 诊断 | 指出点击等同喜欢、历史混杂、过度概括三类错误 | 三份报告分别记，不合并成一个勾 |
| T4b 修正重跑 | 实际恢复可比条件、仅改参数并重新计算 | 修正前后历史/参数/输出；只口头说不算完成 |
| T4c 限制结论 | 用具体观察写出支持范围与至少一个未知 | 保留改写原文，不只记“答对” |
| T5 导出 | 实际保存本次记录并找到可复核字段 | 记录文件名、版本；失败注明原因 |

提示次数与最高帮助等级同时记录，H3 主持人代操作不能记为参与者独立完成。界面反馈本来属于学习体验，不算主持人提示，但可记录是否阅读了反馈。

## 6. 本题本能支持的分析范围

前后题保持相同题型、评分上限和排序计算步数，换用篮球/音乐与不同数值；这改进了旧稿后测额外增加权重比较步骤的问题，但**不证明两套题测量等价**。题目数量少、答案可能受短时记忆和相近结构影响，分数变化不能单独归因于作品，也不能声称标准化学习提升、统计显著或长期迁移。

优先报告每题真实原始表现、典型解释、混杂报告是否真正修正和卡住位置；如报告总分，说明完整配对人数、每人前后分数与限制。
