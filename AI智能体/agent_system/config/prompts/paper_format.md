- 页眉：**每页顶部居中**显示"贵州财经大学本科生毕业论文（设计）"，宋体五号。
- 页码：前置部分（声明/摘要/目录）用罗马数字 I、II、III…；正文从第 1 页起用阿拉伯数字。
- 页边距：上下 2.54cm，左右 3.17cm（Word 默认即可）。

3. 论文题目居中，如"论文题目：基于CNN-LSTM的高速公路流量预测研究"（宋体三号加粗，题目长时换行）。

## 三、声明页（第 2 页）

标题"声明及论文使用的授权"（黑体三号居中），正文为固定声明文本（本人郑重声明所呈交的论文是我个人在导师的指导下独立完成的……论文作者签名栏 + 学校保留使用学位论文规定 + 论文作者签名/指导教师签名/签名日期栏）。

## 四、摘要与目录

- **中文摘要**：标题"摘要"（黑体三号居中），正文为研究背景-问题-方法-数据-结果-结论的 250 字左右摘要，末尾换行"关键词：XXX；XXX；XXX"（3-5 个，分号分隔）。
- **英文摘要**：标题"Abstract"居中，内容为中文摘要的英文翻译；末尾"Keywords: ..."。
- **目录**：标题"目 录"（黑体三号居中），列出 章/节/小节 及页码。

## 五、正文格式

- **章标题**（如"1 绪论"）：黑体三号、居中、加粗。
- **节标题**（如"1.1 研究背景与意义"）：黑体四号、左对齐、加粗。
- **小节标题**（如"3.2.1"）：黑体小四、左对齐、加粗。
- **正文**：宋体小四（12pt）、**首行缩进 2 字符**、1.5 倍行距。
- **图表**：图下方、表上方标注"图 X-X / 表 X-X + 标题"，宋体五号。
- 参考文献引用在正文中用 [1][2] 上标标注。

## 六、章节结构（本科毕业论文标准结构）

1. 绪论（1.1 研究背景与意义 / 1.2 国内外研究现状 / 1.3 本文研究内容及结构安排）
2. 相关理论与技术基础（2.1 深度学习基础知识 / 2.2 预测任务概述 / 2.3 卷积神经网络CNN / 2.4 长短期记忆网络LSTM / 2.5 混合模型结构）
3. 数据预处理与特征工程（3.1 数据来源 / 3.2 数据清洗与处理 / 3.3 数据归一化与序列构建 / 3.4 数据集划分）
4. 模型构建（4.1 模型整体架构 / 4.2 各模块设计 / 4.3 训练策略与优化 / 4.4 超参数设置）
5. 实验设计与结果分析（5.1 实验环境与评价指标 / 5.2 对比模型设置 / 5.3 实验结果与分析 / 5.4 消融实验与时段分析）
6. 结论与展望（6.1 研究总结 / 6.2 研究不足与展望）

## 七、文末部分

- **参考文献**：标题"参考文献"（黑体三号居中），条目按 GB/T 7714-2015 格式：[序号] 作者. 题名[文献类型]. 出版信息, 年份.
- **致谢**：标题"致谢"居中，感谢导师、学院、家人朋友等，300 字左右。
- **附录**：附录 A/B 标题居中，内容为代码示例等。

## 八、写作风格（模仿参考论文）

- 语言严谨学术化，避免口语；长句为主但通顺。
- 绪论部分：先讲背景意义（现实问题+ITS+预测的重要性），再梳理国内外研究现状（统计方法→机器学习→深度学习分阶段），最后交代本文研究内容与结构。
- 实验部分给出具体数值指标（MAE/RMSE/MAPE/R²），对比分析与消融实验。
- 参考文献数量 20-40 条，中英文混合。
