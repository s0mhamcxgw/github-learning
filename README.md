## 从哪里开始

初学 Python 可先看 `Python基础`，接着看 `numpy基础` 和 `数据科学基础`。机器学习相关内容在 `人工智能与机器学习`、`机器学习脚本` 与 `课程实验`。

`.ipynb` 可以在本地 Jupyter 或 PyCharm 中打开。GitHub 的笔记本页面用于查看保存的代码和输出，不会自动执行代码。历史文件中有未完成的草稿，保留它们是为了保存学习记录。

## 运行与依赖

- 各项目独立运行，优先使用项目已有的 `requirements.txt`、`package.json` 和使用说明；没有合并成一个统一环境。
- 数据分析笔记本通常需要 NumPy、pandas、Matplotlib、Seaborn、scikit-learn 和 Jupyter。
- 有些练习保留了原先的 Windows 绝对路径。运行前请按自己的环境调整路径，并自行准备对应数据集。
- `AI智能体/agent_system` 保留依赖与说明文档。真实 `.env`、会话数据和日志没有归档；可参考新建的 `.env.example` 配置本机环境。
- 部分 API 练习的上传副本已用 `REDACTED_CREDENTIAL` 替换凭据。运行时请从本机环境变量或本地 `.env` 读取自己的凭据。
- 个人工具包含磁盘、文件和环境维护操作，请阅读脚本及原使用说明后再运行。

## 保存方式

本次是代码副本归档，本机源文件仍留在各自原目录。软件安装文件、虚拟环境、依赖目录、编辑器缓存、部署内部配置、真实凭据文件及重复的打包验收副本不属于本次归档范围。

`个人项目/数媒比赛` 中有三个作品在本机仅找到 `site/dist` 形式的静态成品，已连同必要资源保存，并在归档说明中列出。其他项目优先保留源代码。

不同文件名的历史版本仍保留各自名称，避免丢失课程或实验编号。本次仅归档已经发现并核对的个人代码目录，不是整盘文件备份。
