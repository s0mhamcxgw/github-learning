# 看见分母——数据比较的交互取证台

版本1.0.0，2026年10月18日。

双击本文件夹中的“打开作品.html”，或打开“site/dist/index.html”。使用近期版本Edge、Chrome或Firefox；保留文件夹结构。无需安装、登录、API密钥或联网，全部核心资源本地提供。

## 先体验这5步

1. 看汇总：核对52.5%和77.5%的分子分母，选择初始判断。
2. 拆分母：两方案的基础/进阶参与者构成不同，但A在两层中均高5个百分点。
3. 换权重：合并样本结构下两层各50%，A为67.5%、B为62.5%。拖动权重重新计算，观察原始数据没有被改写。
4. 审结论：检查过度推断，自己填写有范围的结论，导出报告。
5. 数据台：查看/下载原始CSV，载入自己的两组分层计数，导出JSON后再导入复算。

点击“自动导览”可以观看九步演示。开始导览会重置本次实验，并在后段切换伯克利案例；可暂停、前后翻步或结束。关闭/刷新页面会丢失未导出的结论，作品不使用云端或浏览器持久化存储。

## 文件位置

- site/dist：全部应用代码和内置案例。engine.js为独立计算引擎，app.js为界面和导入导出逻辑。
- 作品截图：实际浏览器截图，含手机布局。
- 演示视频：实际程序自动操作录屏，配本机合成语音，非学生原声。
- 参赛材料：作品说明PDF、申报文字、运行/方法说明、AI和资源说明、答辩稿、真实试用执行材料及提交清单。
- 验收材料：计算和浏览器检查记录。不是学生用户研究。
- 教学数据：三个案例的原始CSV及来源说明。

导出文件由浏览器下载，请选E盘项目目录保存；作品不能替你更改浏览器下载设置。主动点击资料来源链接才会访问外网。

## 申报建议与待办

建议归类：自主选题 → 智慧教育与科普创作类。目标是帮助大学生理解统计比较中的样本结构与推断边界；提交前按最终指南和学校意见核对类别。一件作品只报一项。

AI助手本轮完成代码、交互设计和文档初稿、工程验收与合成语音演示。尚未核实具体学生姓名、分工、实质贡献或真实试用。请本人和队友实际审阅数据与公式、运行作品、作出修改、组织真实试用并记录贡献；不能直接将AI生成过程声明为学生独立完成。

作品已实现不等于已完成赛事报名。仍需本人确认学校内部截止、报名信息、实际成员和教师、系统承诺书签章、材料匿名及“提交审核”。不能保证获奖。

## 数据与计算边界

学习支持、服务响应为原创教学合成数据；伯克利数据为R官方UCBAdmissions的1973年六院系汇总。标准化属于给定参考结构下的描述性重加权，非因果识别或显著性检验，不证明歧视存在或不存在。全部输入可核对，零分母/缺失组别会被拒绝载入。

私有在线预览地址发布成功后记录在“参赛材料/交付与提交清单.md”。私有地址可能需要登录，正式评审应优先使用离线包，或按学校要求另行落实可访问地址。
