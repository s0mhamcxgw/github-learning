# 黔数 · 数据政策研究台

面向贵州财经大学大数据技术与工程方向，依据导师提出的六个主题收集资料：数据要素流通、数据交易、数据工厂、数据质量评估、高质量数据集建设、可信数据空间。

## 日常使用

1. 每日阅读：按原文发布日期查看资料。“今日发布”只统计发布日期为北京时间今天的资料，不将旧文件重新算作新发布。
2. 全部资料库：按主题、类型、地区、发布时段筛选，也可搜索标题、摘要、文号、来源。
3. 点击标题查看提要、来源、文号、状态与阅读问题；“阅读官方原文”打开官方网页或PDF。
4. 收藏、标为已读、写笔记后，可在“我的阅读夹”导出CSV或Markdown摘记。
5. 收藏和笔记只保存在当前浏览器。换设备或清除浏览器数据前，请先导出备份。下载位置由浏览器设置决定，建议另存到E盘项目的outputs目录。
6. “信息源与更新”显示实际检查结果、源站状态及定时计划状态。手动检查有3分钟间隔保护。

## 资料范围与核对

首批14条基础资料均保留公开出处，包含国家政策、贵州地方性法规、信通院报告、标准项目及正式数据质量标准。自动新收录按关键词分类，保留待核对标记。标准项目、技术文件、征求意见稿与已发布标准分别标注。

自动采集覆盖国家数据局、贵州省大数据局等列明的公开页面；每轮每源最多新增4条HTML详情。信通院等站点可能限制访问，标准平台动态检索及PDF仍需人工补充。不能把来源不可访问理解为该方向没有新资料。

未找到“制定26级学期科研学习计划”文件，本版依据用户明确提供的导师要求制作。

## 本地开发

需要Node.js 22.13及以上。项目使用Vinext、React、Cloudflare Workers和D1。源码、数据库迁移、构建产物与测试截图均位于本E盘项目中。

安装依赖：`npm run install:ci`；生成迁移：`npm run db:generate`；构建：`npm run build`；预览：`npm start`。本机npm包装器存在路径兼容问题时，可用Node直接调用已安装的npm-cli.js；此任务未修改系统npm配置。

本地数据库需按顺序执行drizzle目录的SQL迁移。线上数据库由Sites部署迁移管理，和本地测试库相互独立。

线上站点保持个人私有访问，后台写入依赖平台私有访问边界；请勿直接改为公开。

每日更新及服务访问说明见UPDATE_WORKFLOW.md。
