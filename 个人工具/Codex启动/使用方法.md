# Codex 代理使用方法

使用猫猫云，保留 ChatGPT 账号登录。

1. 打开猫猫云，选择能够正常访问 ChatGPT 的节点并连接。当前节点已实测可用。
2. 打开“系统代理”，本地代理地址为 `127.0.0.1:10090`。
3. 打开“TUN / 虚拟网卡”。如出现 Windows 管理员确认，允许代理程序创建虚拟网卡。连接模式保留当前可用设置。
4. 双击同目录 `Launch-Codex.cmd`，检查代理端口和 MAOMAOYUN 网卡后打开 Codex。不要同时连接 Proton VPN 或其他 VPN。
5. Codex 保持 ChatGPT 账号登录。对之前已失败的消息点击重试，或重新发送；旧错误记录不会自动消失。账号或供应商切换工具可能覆盖配置，使用期间不要切换到 DeepSeek/API key 档。

修复已将 Windows 系统代理设置为 `127.0.0.1:10090`。启动入口只检查代理和 TUN，并给启动的 Codex 进程设置同一代理环境变量，不更改代理软件的加密配置或 Codex 二进制。

用完后如果要关闭猫猫云，请先在猫猫云关闭“系统代理”，再退出它，避免其他应用继续尝试连接已关闭的本地端口。

修复前的系统代理设置及 Codex 配置已备份到本目录。此次未更换账号、未使用 API key、未删除聊天数据。
