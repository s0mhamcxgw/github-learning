# 开始使用《看见排序》

这是一份本地离线交互科普原型。目标是让非计算机专业大学生学会区分行为与意图、拆解排序，以及诊断错误实验报告、修正条件重算、限定结论。

## 打开作品

双击本文件夹中 **app → index.html**，用近期版本的 Edge、Chrome 或 Firefox 打开即可。无需安装、联网、账号或 API 密钥。请保留 app 内六个文件的相对位置。

核心资源全部本地提供。应用中的“资料来源”链接仅在主动点击时联网访问。浏览器可能保存本机练习进度，不会自动上传；在“我的小结”中可清空。

如果浏览器限制从文件打开，可在本目录运行 `python -m http.server 8788 --bind 127.0.0.1 --directory app`，再访问 `http://127.0.0.1:8788/`。本地服务只用于预览，不代表已发布网站。关闭该命令窗口即可结束服务。

## 建议体验顺序

1. **一次点击**：判断相同点击能否说明两个人的真实动机。
2. **拆开排序**：查看“校园篮球集锦”的算分单，记录点击，比较兴趣值与排名；可打开全部 24 张模拟卡片。
3. **平行实验**：保存快照，只改变右侧权重；先预测第一名，再揭开结果。两支独立重算，不改变历史。
4. **报告纠错**：诊断三份错误报告。第二份必须实际恢复相同历史、重跑计算，再用自己的话改写结论。
5. **我的小结**：导出 JSON 实验记录和 Markdown 可读小结；导入 JSON 时核验版本、动作、排名和分数后重算。

顶端可直接切换章节。练习完成标记仅检查选择、实际操作和是否填写，不对自由文本的理解质量作自动判断。它不是标准化学习测评。

## 内容与模型

24 张卡片分六个主题，每类四张，标题、简介、热度与新鲜度均为模拟教学内容。六类计数初始均为 1，每点击对应类加 2。

`R = 对应主题计数 / 六类计数总和`

`S = λR + (1−λ)(p+f)/2`

按完整精度的 S 降序；同分按 ID 升序；显示保留三位小数。p、f 为固定模拟值，点过的卡仍留在候选池。分数不是喜欢概率。

默认 λ=.6 时，运动卡“校园篮球集锦”的分数从 .300 变为一次运动点击后的 .425；科技卡“纸桥承重小实验”从 .420 变为 .395。同一次点击后仅将 λ 改成 .2，两者为 .475 和 .665。这只说明本模型的两卡相对排序。

前六张的主题覆盖率是不同主题数/6；最大主题占比是最多主题卡数/6。它们不是现实信息茧房、偏见、幸福感或教学效果指标。模型不训练、不接入真实平台，不识别真实心理。
