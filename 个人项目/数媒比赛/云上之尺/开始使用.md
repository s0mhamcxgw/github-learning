# 云上之尺——625米与2毫米之间

版本 1.0.0 / 2026年10月18日。作品形态：离线交互数字叙事。拟报本科及以上组、指定命题“科技+创意，讲好中国故事”，提交前按实际成品与系统名称核对。

完整解压后双击本目录的 **打开作品.html**。也可以直接打开“作品/index.html”。推荐近期桌面 Edge 或 Chrome；无需安装、账号、密钥、Python、Node或联网。原始资料链接需要联网，作品本体不需要。请保留“作品/vendor”目录。

## 先体验这一条路线

1. 序章“入云”：点击开始，进入程序化三维峡谷。
2. “量谷”：依次选择高度、主跨、全长；再切换俯看、桥面、水面视角。拖动画面可旋转，滚轮拉近，“复位镜头”恢复。
3. “寻力”：移动示意车辆，选桥面、吊索、主缆、主塔与锚碇；拖动分解滑杆辨认构件。
4. “筑桥”：先试“先装桥面？”，再依次建造。第5阶段可以调桥面节段展示进度。可点击时间点回看。
5. “入微”：主缆217根索股 → 每股91根钢丝 → 钢丝直径5.7毫米 → 单次毫米偏移 → 持续观测。最后根据资料辨认三句话的差异。
6. “抵达”：点“看2分钟时刻”，两条示意路径使用同一时钟。路线不是实际导航。
7. “留尺”：写自己的理解，生成1600×2000观察卡，导出Markdown手记和JSON进度。

顶部“导览”约2分半，可暂停，结束会恢复个人进度；它不会冒充个人探索。声音需要主动开启，是原创程序合成意象。减少动态或系统同名设置可以停止环境运动；手动触发的路线推演仍可运行。手机页面向下滚动可见完整面板与章节导航。

进度尽量保存在当前浏览器本地。不同文件位置、浏览器、隐私模式或系统策略可能导致记录隔离或无法保存；重要进度请导出JSON。JSON只接受本版本格式，载入时校验枚举与数值范围。清除进度入口在“资料与制作→创作与实现”。下载文件时请选择E盘。

## 内容边界

625米是桥面至水面的垂直高差；2毫米来自基准索股架设中同一位置持续观测一周、相对高差稳定的报道，不能扩大成全桥任意部位的绝对误差。三维地貌和未标注构件尺寸是原创叙事概括；传力为定性关系；观测曲线是明确标记的创作示意；路线为关系图。作品不是工程设计、数字孪生、现场测绘或实时监测系统。

本版本由AI助手辅助制作，不虚构学生独立完成、现场调研、工程专家合作或学习效果。参赛前应如实完成学生审阅、修改、运行理解和贡献记录。是否获奖由正式评审决定。
