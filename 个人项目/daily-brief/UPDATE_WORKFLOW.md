# 每日资料更新操作

用途：贵州财经大学大数据技术与工程方向的个人研究资料台。导师指定六个主题：数据要素流通、数据交易、数据工厂、数据质量评估、高质量数据集建设、可信数据空间。收集法律法规、政策、研究报告、标准和技术文件，贵州优先、兼顾全国。

此站保持创建时的 owner-private 访问范围。写入接口依赖平台的私有站点访问边界，不应改为公开站点。

## 无人值守更新

1. 用 Sites `get_site` 读取当前关联站点，确认仍为个人私有站点，并获取 current_live_url 与平台提供的服务访问方式。不要输出、落盘或转发任何凭据。
2. 若返回 siwc_bypass_bearer_token，在内存中持有；向同一站点的 `/api/refresh` 发送 POST，使用 `OAI-Sites-Authorization: Bearer <token>`。无需请求正文。不要将凭据发到其他主机；禁止自动跟随跨站重定向。平台服务访问不依赖用户在浏览器登录。
3. 接口只读取源码中 SOURCES 列明的公开官方信息源。它自动按导师主题匹配、按URL去重，将新增记录保存在D1；自动分类保留待核对标记。报告PDF及动态标准检索入口需人工核查。每轮每个信息源最多采集4条未收录的HTML详情，后续轮次继续补充。
4. GET 同站点 `/api/documents`（同样的平台访问头）读回 lastRun 以及 documents，核对新增记录和各来源状态；接口的 busy 表示另一任务运行中，cached 表示3分钟内复用上一轮记录，均不应重复创建记录。
   若贵州来源超时或报告来源受限，用可用的联网检索查找过去7天的官方资料，重点检索六个研究主题，核对原文标题、链接、发布日期，不能只根据搜索摘要推断政策效力。已找到的有效资料可 POST 同站点 `/api/import`，正文为 `{"documents":[{"title":"原文标题","url":"HTTPS官方链接","date":"YYYY-MM-DD或null","region":"贵州或全国","kind":"法律法规/政策文件/研究报告/标准/技术文件/行业动态/政策解读之一","topics":["六个主题之一"],"summary":"200字内提要","number":"可选文号"}]}`。来源域名由服务端白名单限制；无法核对的日期留空；政策解读不得当正式政策。每批至多40条，按URL去重。此路径也用于人工核查后补充PDF与动态标准条目。读回确认记录确实保存。
5. 正常无新增时保持安静。发现与六个方向直接相关的重要新政策、法律法规或标准发布时才简短提示；若连续失败或需要用户处理连接问题，说明具体来源及失败情况。不能把抓取失败报告为无新资料。

首次运行须实际调用接口并读回，不能仅以保存计划证明采集成功。服务访问不可取得时，不要创建无效定时计划，不要改变网站访问范围。

## 功能与边界

- 收藏、已读与研究笔记保存在当前浏览器；CSV与Markdown导出用于资料归档。无法跨设备同步。
- 首批14条资料经公开来源核查；自动新增资料需人工确认版本、发布日期、效力和类型。内容提要与阅读问题是学习辅助，不构成原文。
- 数据库记录长久保留。当前列表接口最多返回2000条自动资料，附加首批资料；大规模长期使用需要后续增加服务端分页。
- 尚未找到用户提及的“制定26级学期科研学习计划”文件，不能声称已依据该计划定制。
