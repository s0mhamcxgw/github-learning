# 背上的花——苗族背带的层叠记忆

版本1.0.0，2026年10月18日。拟报指定命题“民族文化·创新表达”。

## 打开与体验

完整解压后，双击本文件夹内的“打开作品.html”。也可直接打开“site/dist/index.html”。使用近期桌面Edge、Chrome等浏览器，不需要安装、登录、密钥或联网。保留目录结构。

先体验这一条主线：

1. 序章看完整原创艺术构成。
2. 第一章拖动折叠滑杆，看同一块P07布片的变化。
3. 第二章将布片拖到虚线目标，或用按钮/画面聚焦后的Enter放置。可撤销、自动叠放与逐层拆看。
4. 第三章切换微观、局部与整体，找到同一个P07；可轻转整体。
5. “我的叠放”保留实际放置数量；“完整设计参考”明确切换，不代表本人已经完成。后续作品卡按当前模式绘制。
6. 第四章选择当代祝愿、写下短句，导出1600×2000像素PNG。浏览器下载时请自行选择E盘目录。
7. 尾声查看资料与创作说明。自动导览可随时暂停或结束，结束后恢复导览前的个人状态。

声音需主动开启，使用原创程序合成环境音与拟音，并非传统音乐录音。减少动态可停止漂浮与过渡。作品不持久保存操作，刷新会丢失当前状态与短句，请先下载留存。

- 制作记录：实际图像提示词、实现说明与助手制作记录。
- 验收材料：助手工程检查结果，不是用户研究或第三方认证。

## 作品与研究边界

这是公开资料研究基础上的当代数字艺术作品。文化入口是中央民族大学民族博物馆的具体背孩带记录。24片构图、配色、折叠示意、三个尺度和当代祝愿属于原创设计；不冒称馆藏复刻、传统工艺完整教学或固定纹样释义。背景照料人物是虚构艺术意象，未复制馆藏照片。
