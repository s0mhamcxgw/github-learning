# 一单之变 · 使用与交付说明

作品名称：一单之变——可解释接单与交期推演工作台。版本 1.0.0。制作日期：2026-10-15。

## 直接体验

- **自动观看：** 双击同目录的[自动演示.html](./自动演示.html)。进入十步自动导览，可以暂停、前后切换或结束，不需要先填写订单。
- **自由操作：** 打开[应用首页](./site/dist/index.html)。使用近期版本的 Edge 或 Chrome，允许 JavaScript；不用安装、登录、联网或配置 API。
- **私有在线预览：** [作品预览](https://one-order-promise-lab.surehippo1.chatgpt.site)。该地址保留所有者私有访问，可能要求登录，不能直接当作评审公开地址。正式材料可使用离线程序包。
- **视频：** `演示视频/一单之变_评审演示_合成语音.mp4`，实际程序自动操作录屏，附本机合成语音。不是学生原声或用户试用。

解压时保留目录结构。不要只复制 index.html，须同时保留旁边的 JS、CSS 和 SVG。

## 作品会做什么

1. 核对已有订单是否存在可行排程。
2. 加入一张待接新单，检查连续工时、前置工序、资源与交期。
3. 在可用条件下给出具体冲突，例如两道工序必然争用同一时段的制作人。
4. 比较新单改期、开放午间和允许委派的人工；没有把协作假设变成额外机器。
5. 对工时、准备时间和设备停用做指定扰动，并重新排程。
6. 修改或导入约束，导出包含输入和排程的 JSON 及文字报告。

内置三个原创合成场景：连续工时、共享设备、工时余量。它们不是商户合作、行业工艺标准或真实订单。

## 不需要持续维护的部分

离线作品不依赖服务器、付费模型、外部数据库、账号或实时素材。演示已自带数据，观众可以直接观看。正常离线使用产生的导出文件由浏览器下载，不上传到外部服务。

作品采用最多 4 天、16 道工序的离散模型；不保证大规模排程性能，也不代替生产工艺指导。找到可行排程不代表最优，压力样本通过数不代表现实准时率。
