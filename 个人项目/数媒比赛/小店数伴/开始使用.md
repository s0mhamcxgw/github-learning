# 小店数伴：开始使用

当前版本：0.1.0，2026年11月1日。本地可运行原型，尚未进行真实商户需求与经营成效验证。

## 启动

1. 在当前文件夹双击 `启动小店数伴.cmd`。
2. 浏览器会打开 `http://127.0.0.1:8766`。保持命令窗口打开，使用完关闭该窗口即可停止服务。
3. 首屏已内置公开零售订单，不需要先准备商家数据或账号。

本机已验证环境：Python 3.13.2、pandas 2.3.3、openpyxl 3.1.5和Microsoft Edge。移到另一台电脑时，需要Python 3.10或以上版本及依赖；在作品目录执行：

```powershell
python -m pip install -r requirements.txt
python -X utf8 app.py --open
```

如果8766端口被占用，可执行 `python -X utf8 app.py --port 8767 --open`。应用本身不需要联网；首次安装依赖需要网络。手机布局已经检查，但当前服务只绑定本机，不直接向其他设备提供访问。

## 建议按这个顺序体验

1. **经营概览**：切换分析天数，查看每天金额和前一个同长区间的对比。
2. **数据体检**：查看重复候选、缺失、日期与数值问题；切换“剔除精确重复候选行”，观察分析结果变化。
3. **商品洞察**：搜索商品，查看同购样本量、支持度、置信度和提升度。
4. **行动清单**：查看建议的数据依据，填写真实核查笔记和状态。没有试用时保持空白，不预填成效。
5. **来源与方法**：核对公开数据许可、币种、历史日期、字段映射和计算局限。

## 导入自己的文件

支持CSV和XLSX，单文件不超过35MB、60万行。需要订单号、日期、商品、数量，以及行实付金额或单价；商品编码可选。每一行应是一项订单商品明细，不能把整笔订单总金额重复放到每个商品行。

导入时明确币种和日期顺序。默认采用年-月-日。仅在文件确实使用C开头表示取消单时启用对应选项。原文件不会被改写；上传内容只保存在本机服务进程内存，关闭后清除。

## 导出在哪里

点击“导出报告”或“导出核查记录”，结果保存到本作品目录的 `exports` 文件夹。界面会提示实际路径，并可打开报告。核查笔记保存在当前浏览器的本机存储中，清理浏览器数据后会丢失，建议及时导出。

## 数据与当前边界

示例为UCI Online Retail中2011年10—11月的145,453条原始订单明细，作者Daqing Chen，CC BY 4.0。它是英国线上零售历史数据，不代表贵州小店；币种为英镑，不做汇率换算。样例已移除CustomerID和Country，保留原表行号。
