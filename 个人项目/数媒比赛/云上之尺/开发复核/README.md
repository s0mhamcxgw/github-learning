# 软件复核

打开作品不需要Node或Python。安装Node的电脑可运行：

```text
node engine-check.cjs
```

该脚本位于作品完整目录的“开发复核”，通过相对路径载入“作品/engine.js”。不依赖npm包。

8组检查覆盖公开尺度/单位、217/91点阵、曲线连续性、地貌范围、前序关系、导入白名单与边界、非法输入、解释性数据与导出措辞。实际浏览器检查结果见“验收材料/浏览器核查.json”。这些是助手软件QA，不是工程安全检测、学生贡献证明或真实观众研究。

核心源代码随应用交付。制作脚本、自动浏览器脚本、语音中间文件与PDF渲染中间图保存在E盘项目的work/高桥，正式匿名成果不包含本机路径或浏览器用户数据。
