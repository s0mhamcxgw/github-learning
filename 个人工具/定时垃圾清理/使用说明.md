# 电脑垃圾检查与定时清理

双击“启动清理程序.cmd”打开界面，点击“检查占用”查看各类文件占用；报告写入旁边的 `reports` 文件夹，清理日志在 `logs` 文件夹。

## 自动运行

点击“启用每周清理”后，每周日北京时间 20:00 自动运行，使用 Windows 任务计划程序，不需要常驻后台或安装 Python。

电脑开机且当前用户处于登录状态时运行（锁屏也可）；不会唤醒或开机。错过时间后，在满足运行条件时补跑。关闭自动清理可使用界面按钮或双击“关闭自动清理.cmd”。

仅以普通用户权限运行。无法读取或删除的 Windows 临时文件会跳过，不会为了清理而要求管理员权限。

## 清理规则

- 只删除当前用户 `%LOCALAPPDATA%\Temp` 和 `%WINDIR%\Temp` 里的普通文件。
- 创建、修改、访问时间必须均早于 14 天前；Windows 访问时间可能延迟记录，时间戳不能证明文件一定无用。
- 跳过链接、连接点、安装包和程序文件，以及名称包含 Codex、OpenAI、ChatGPT、安装器、部分开发工具标识的临时工作目录。
- 删除前重新检查路径和时间，并尝试独占打开；使用中、只读或无权限的文件会跳过。
- 不递归删除文件夹；文件永久删除，不经过回收站。
- 不清理桌面、文档、下载、聊天记录、浏览器登录信息、软件本体、系统组件、回收站或浏览器缓存。

检查模式会统计常见浏览器、显卡、包管理器缓存和回收站。缓存可以重新生成，但也有性能、离线网页或调试用途，不能把所有占用都认定为垃圾。统计不包括链接目标或无权限目录，实际释放空间也可能与逻辑文件大小不同。

程序位置不要直接移动，否则已登记的任务会找不到脚本。需要移动时先关闭自动清理，移动后重新启用。要卸载，先关闭自动清理，再删除本程序文件夹。

## 命令行

在本目录使用 Windows PowerShell 执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Cleaner.ps1 -Mode Scan
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Cleaner.ps1 -Mode Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Cleaner.ps1 -Mode InstallSchedule
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Cleaner.ps1 -Mode RemoveSchedule
# 以下会永久清理符合条件的临时文件：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Cleaner.ps1 -Mode Clean -ConfirmClean
```

报告和日志可能包含本机文件路径，请按个人信息妥善保存。日志不自动删除，可自行整理。
