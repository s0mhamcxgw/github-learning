## 一、项目概述

### 1.1 项目定位

本项目是一个 **AI 智能体（AI Agent）系统**，基于阿里云百炼大模型（qwen3.8-max）开发。
与普通聊天机器人不同，本系统的核心特点是：**不只会"说"，还会"做"**——能真的执行 Python 代码、读写本地文件、生成 Word/Excel/PPT/PDF 等真实文件。

### 1.2 技术栈

| 类别 | 技术 |
|------|------|
| 编程语言 | Python 3.13 |
| 大模型 API | 阿里云百炼（OpenAI 兼容模式） |
| 文档生成 | python-docx / openpyxl / python-pptx / pypdf |
| Web 界面 | Gradio |
| 配置管理 | python-dotenv |
| 数据存储 | JSON 文件（无数据库） |

### 1.3 整体架构（五层）

```python
# 第41-120行：process 主流程（生成器，ReAct循环）
def process(self, user_input, plan=""):
    # 第1步：生成任务计划
    plan_text = self._make_plan(user_input)
    yield {"type": "plan", "content": plan_text}

    # 第2步：ReAct循环（最多20轮）
    for iteration in range(1, self.max_iterations + 1):
        messages = [system] + conversation[-10:]   # 只带最近10轮（防上下文爆炸）
        response = llm.chat_non_stream(messages)    # 问AI该干什么
        decision = self._parse_decision(response)   # 解析AI的JSON决策

        if decision.get("tool"):          # AI说调工具
            result = self.tool_manager.execute_tool(decision["tool"], **decision["params"])
            yield {"type": "tool_result", ...}  # 把结果发给前端
            conversation.append({"role":"user", "content": f"工具结果：{result}"})
        elif decision.get("done"):         # AI说做完了
            break

    # 第3步：验证产出文件
    verified = self._verify_files()
    # 第4步：交付总结
    yield {"type": "done", "content": deliver, "files": self.files_produced}
```
> 要点：这是整个项目的心脏。ReAct = Reasoning + Acting，AI每轮决定"调什么工具"或"做完了"，循环直到完成。

```python

```python
# 第181-214行：_parse_decision 解析AI的JSON（三层容错）
def _parse_decision(self, response):
    try:
        data = json.loads(response)        # 第1层：直接解析
        if "tool" in data or "done" in data: return data
    except: pass
    if "```json" in response:             # 第2层：从markdown代码块里抠
        json_str = response.split("```json")[1].split("```")[0]
        data = json.loads(json_str)
    start, end = response.find("{"), response.rfind("}")  # 第3层：暴力截取
    data = json.loads(response[start:end+1])
```
> 要点：LLM输出JSON格式不稳定，做三层兜底解析。这是工程经验。

### 3.1 这个项目到底干了什么？

**一句话**：把普通的大模型聊天机器人，升级成了一个**能自己规划、自己动手干活、有记忆、分场景工作**的 AI 智能体。

### 3.3 核心技术亮点

1. **ReAct自主推理**：不是一问一答，而是"思考→调工具→看结果→再思考"循环
2. **真动手干活**：12个工具能真写Word/Excel/PPT/Python代码/跑程序
3. **记忆系统**：短期存对话历史，长期自动提取用户偏好和经验
4. **场景化分身**：4个专属Agent，各有不同处理流程和验收标准
5. **设计模式**：工厂模式（Agent管理）、模板方法（场景基类）、单例（LLM客户端）
6. **工程健壮性**：JSON三层容错、产出物验证防吹牛、危险命令黑名单、最大迭代保护

### 3.4 可以深化的方向（面试加分项）

1. **记忆检索升级**：现在是关键词匹配，可接embedding向量检索（FAISS/Chroma）
